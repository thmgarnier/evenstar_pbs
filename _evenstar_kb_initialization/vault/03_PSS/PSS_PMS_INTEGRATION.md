# PSS ↔ PMS integration

PSS engineering evidence can support controlled project deliverables. Promotion selects useful runs, studies, reports or design basis; it does not bulk-copy every PSS result into PMS.

PSS remains source of calculation evidence. PMS owns the selection/reference, deliverable revision, review and issue context. Superseded-evidence detection and the exact promotion payload remain open.
