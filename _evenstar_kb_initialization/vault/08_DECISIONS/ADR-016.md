# ADR-016 — Historical demos follow current system boundaries

## Context

The earlier PBS brain named Process, Control, Plant 3D, Data, Project, Workflow and Explorer demos sharing a backend.

## Decision

Retain that historical portfolio record, but interpret current responsibility using ADR-001: computation belongs in PSS, delivery in PMS, and canonical plant views in PBS.

## Consequences

This supersedes treating the seven demo names as permanent PBS subsystem ownership. It does not claim migration was implemented or settle mixed control/provisioning/review facets. The seven historical ADR summaries remain preserved.

## Alternatives

Silently rewrite the old demo list or retain its scope unchanged; both lose architectural evolution.

Alternatives here are curator analysis, not a claim that a historical options review occurred.
