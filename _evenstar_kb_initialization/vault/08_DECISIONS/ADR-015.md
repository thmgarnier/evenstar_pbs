# ADR-015 — Explicit Project Data exchange and reproducible runs

## Context

Project input reuse is valuable only if later source edits do not silently rewrite calculation history.

## Decision

Distinguish local/project/linked inputs; make Read/Write/Compare/Refresh explicit and retain snapshots/version references sufficient for historical reproducibility.

## Consequences

Newer source data is visible for deliberate comparison/update. Snapshot storage, concurrency and refresh UI details still require contracts.

## Alternatives

Live links alone or automatic two-way synchronization cannot preserve a historical basis when source records change.

Alternatives here are curator analysis, not a claim that a historical options review occurred.
