# ADR-001 — PBS / PSS / PMS system responsibilities

## Context

Earlier PBS demos covered behavior and delivery alongside plant design. The current briefs and user mandate establish three constituent systems.

## Decision

PBS owns plant definition; PSS owns calculation/model behavior; PMS owns project delivery. Shared identity and explicit contracts connect them.

## Consequences

A feature follows its responsible domain even when displayed elsewhere. Detailed cross-system review/provisioning contracts remain open.

## Alternatives

Keep all earlier demos as PBS modules, or build disconnected tools with duplicate identities; neither matches the current explicit boundary.

Alternatives here are curator analysis, not a claim that a historical options review occurred.
