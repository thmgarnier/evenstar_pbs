# ADR-004 — One engineering object, many representations

## Context

P&ID, 3D and data views can otherwise become disconnected definitions of the same equipment.

## Decision

Views and external references represent one canonical engineering object.

## Consequences

Selection/navigation and edits must resolve shared identity. This does not impose identical interaction patterns on all views.

## Alternatives

Independent equipment records per application or decorative-only 3D would contradict the source model.

Alternatives here are curator analysis, not a claim that a historical options review occurred.
