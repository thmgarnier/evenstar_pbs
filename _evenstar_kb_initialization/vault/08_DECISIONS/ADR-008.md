# ADR-008 — Per-project PSS Engineering Register

## Context

PSS reuses project input knowledge and publishes curated analysis in a project-specific collaborative register.

## Decision

Support one PSS Airtable base per PSS-enabled project through create/connect and versioned template configuration.

## Consequences

Register Project UUID/base/schema mappings and hide ordinary mapping details from users. Actual provisioning mechanism and optional domain templates remain unresolved.

## Alternatives

A universal PSS base or manual table-ID setup as ordinary workflow does not match the stated per-project direction.

Alternatives here are curator analysis, not a claim that a historical options review occurred.
