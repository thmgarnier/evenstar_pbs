# OQ-007 — PSS register schema and Project Data API

**OPEN QUESTION — P1**

## Decision needed

Select the minimum core schema, normalized versus convenience tables, and typed read/write/compare API.

## Options / investigation

Use reusable compositions/species, variables/cases and a minimal model/run/publication set. Source recommended tables are not immutable.

## Why it matters

Controls usability, identity mapping and data portability.

Prepare a concrete domain example and options, identify affected owners/contracts/requirements, and obtain an explicit architectural resolution. Record it in an ADR or requirement update; preserve this question with its resolution link.
