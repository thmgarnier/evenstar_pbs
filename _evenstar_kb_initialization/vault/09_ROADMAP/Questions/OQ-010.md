# OQ-010 — Project provisioning and versioned base migration

**OPEN QUESTION — P0**

## Decision needed

Choose the project UUID issuer/provisioning coordinator, create/connect behavior, template provisioning mechanism, mapping registry and migration/recovery strategy.

## Options / investigation

Verify actual Airtable API/template capabilities when implementation is authorized. Compare manual assisted setup and automated provisioning without assuming either is available; define partial failure and permissions.

## Why it matters

Affects both bases, shared identity and ordinary users avoiding table-ID setup.

## Resolution path

Prepare a concrete domain example and options, identify affected owners/contracts/requirements, and obtain an explicit architectural resolution. Record it in an ADR or requirement update; preserve this question with its resolution link.

No individual owner or deadline has been assigned.
