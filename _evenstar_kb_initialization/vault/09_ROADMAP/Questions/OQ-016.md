# OQ-016 — PBS reference synchronization

**OPEN QUESTION — P1**

## Decision needed

Define PMS engineering-reference refresh, freshness, source revision pinning and deleted/retired object behavior.

## Options / investigation

Use UUIDs for identity; tags/names remain display caches. Decide what happens when a referenced object changes after issue.

## Why it matters

Keeps delivery context usable without an independent plant database.

## Resolution path

Prepare a concrete domain example and options, identify affected owners/contracts/requirements, and obtain an explicit architectural resolution. Record it in an ADR or requirement update; preserve this question with its resolution link.

No individual owner or deadline has been assigned.
