# PMS portfolio

Cross-project reporting is future architecture around the preferred per-project PMS bases. Candidates include a Supabase portfolio register, aggregation service, Airtable portfolio base, BI layer or Evenstar dashboard.

Do not merge all project data into one giant base merely to simplify a portfolio view. Decide aggregation fields, freshness, access boundaries and source links after project delivery works. No portfolio implementation or tool choice is accepted.
