# Connection

A connection expresses a relationship between endpoints. Physical connectivity belongs to PBS and should be reusable by PSS. It is distinct from pipe geometry and from a PSS computational stream.

Connection types, compatibility, directionality and how nonphysical control/signal relationships are represented remain model questions.
