# System

A plant System organizes related engineering objects in PBS and supports tags, visibility, search and external references. It is distinct from the software subsystems PBS/PSS/PMS.

PMS Systems/Areas can reference PBS context or express delivery/WBS grouping; those meanings require an explicit mapping rather than copied engineering definitions.
