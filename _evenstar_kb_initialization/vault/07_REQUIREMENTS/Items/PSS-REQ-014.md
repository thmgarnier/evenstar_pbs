# PSS-REQ-014 — Local calculation capability

**Classification:** REQUIREMENT

**Status:** Proposed product intent. **Implementation:** Unverified.

PSS should permit basic local calculation without avoidable cloud dependence.

## Acceptance criteria

An agreed standalone calculation can run with network unavailable; offline source-cache behavior is explicit.

These criteria are derived verification targets, not executed product tests.
