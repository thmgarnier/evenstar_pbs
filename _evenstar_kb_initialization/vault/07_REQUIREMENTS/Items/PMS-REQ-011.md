# PMS-REQ-011 — Delivery Interfaces

**Classification:** REQUIREMENT

**Status:** Proposed product intent. **Implementation:** Unverified.

PMS should provide project/deliverable/review Interfaces beyond raw tables.

## Acceptance criteria

The agreed MVP lets a user inspect deliverables, linked engineering/evidence and review/issue status through Interfaces.

These criteria are derived verification targets, not executed product tests.
