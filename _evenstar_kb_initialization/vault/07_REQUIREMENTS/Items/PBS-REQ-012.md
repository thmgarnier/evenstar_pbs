# PBS-REQ-012 — Constraint-aware routing

**Classification:** REQUIREMENT

**Status:** Proposed product intent. **Implementation:** Unverified.

PBS should eventually support routing with compatible ports, obstacles/corridors and manual controls.

## Acceptance criteria

An agreed routing fixture demonstrates constraints, waypoints/locked segments and visible conflicts; exact objectives remain open.

These criteria are derived verification targets, not executed product tests.
