# PSS-REQ-001 — Start from Project

**Classification:** REQUIREMENT

**Status:** Accepted product intent. **Implementation:** Unverified.

PSS shall seed models from reusable project information rather than requiring repeated entry of known data.

## Acceptance criteria

Select project composition/conditions or PBS topology, validate it and seed a model with source links.

These criteria are derived verification targets, not executed product tests.
