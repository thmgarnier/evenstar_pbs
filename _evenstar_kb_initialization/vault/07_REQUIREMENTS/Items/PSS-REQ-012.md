# PSS-REQ-012 — Standalone thermodynamics

**Classification:** REQUIREMENT

**Status:** Accepted product intent. **Implementation:** Unverified.

PSS shall provide a first-class standalone thermodynamics workspace with visible methods, assumptions, validity, units and provenance.

## Acceptance criteria

Run an agreed pure-fluid/mixture calculation without a plant flowsheet and inspect method, applicable range, units and source context; first method remains to be selected.

These criteria are derived verification targets, not executed product tests.
