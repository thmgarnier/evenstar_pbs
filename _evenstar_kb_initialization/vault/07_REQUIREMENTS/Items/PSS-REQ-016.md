# PSS-REQ-016 — Reusable aqueous analysis

**Classification:** REQUIREMENT

**Status:** Proposed product intent. **Implementation:** Unverified.

PSS should reuse project water analyses in supported aqueous/water calculations.

## Acceptance criteria

Import a known analysis with species, units/basis and provenance into a selected validated calculation.

These criteria are derived verification targets, not executed product tests.
