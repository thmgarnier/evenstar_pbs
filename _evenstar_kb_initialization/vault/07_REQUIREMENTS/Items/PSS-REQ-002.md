# PSS-REQ-002 — Input classes

**Classification:** REQUIREMENT

**Status:** Accepted product intent. **Implementation:** Unverified.

PSS shall distinguish LOCAL PSS INPUT, PROJECT INPUT and LINKED PSS INPUT and allow study values to remain local.

## Acceptance criteria

The UI identifies each class; an unlinked study input can be edited without changing project data.

These criteria are derived verification targets, not executed product tests.
