# PBS-REQ-002 — Canonical P&ID

**Classification:** REQUIREMENT

**Status:** Accepted product intent. **Implementation:** Unverified.

P&ID symbols and connections shall instantiate/reference canonical engineering objects and typed port relationships.

## Acceptance criteria

Place/reference a pump and connect a valid port; the canonical model and inspector expose the same object and relationship.

These criteria are derived verification targets, not executed product tests.
