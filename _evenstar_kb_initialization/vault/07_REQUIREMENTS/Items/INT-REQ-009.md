# INT-REQ-009 — Cross-representation navigation

**Classification:** REQUIREMENT

**Status:** Accepted product intent. **Implementation:** Unverified.

PBS/PSS/PMS integrations shall support navigation through stable engineering relationships.

## Acceptance criteria

From a canonical object, resolve its available representations, calculations and delivery references without guessing by tag text.

These criteria are derived verification targets, not executed product tests.
