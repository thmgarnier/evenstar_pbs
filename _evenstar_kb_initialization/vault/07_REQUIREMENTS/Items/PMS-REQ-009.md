# PMS-REQ-009 — Versioned templates

**Classification:** REQUIREMENT

**Status:** Accepted product intent. **Implementation:** Unverified.

PMS provisioning shall use versioned templates with stable core contracts and registered mapping/version metadata.

## Acceptance criteria

A project can identify its template/schema version; a proposed template change identifies migration impact without silent schema divergence.

These criteria are derived verification targets, not executed product tests.
