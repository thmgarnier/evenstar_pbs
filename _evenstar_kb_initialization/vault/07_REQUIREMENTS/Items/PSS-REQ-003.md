# PSS-REQ-003 — Explicit Project Data actions

**Classification:** REQUIREMENT

**Status:** Accepted product intent. **Implementation:** Unverified.

PSS shall expose explicit selected Read from Project, Write to Project, Compare and Refresh operations.

## Acceptance criteria

Compare changed values/units/revisions, keep or deliberately read/write selected data; no background two-way overwrite occurs.

These criteria are derived verification targets, not executed product tests.
