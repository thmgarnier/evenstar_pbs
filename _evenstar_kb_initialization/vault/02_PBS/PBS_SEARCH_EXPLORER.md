# PBS search and explorer

Search should resolve UUID, KKS, tag, name, type, system, relationships and applicable documents. Selecting an object reveals its connected representations and engineering context.

Candidate navigation includes Plant Explorer, P&ID, Plant 3D, Engineering Data, Piping, Instrumentation, Documents and Changes/History, with Open in PSS/PMS cross-links. Project switching, command palette and object history are shared UX directions. No screen layout is finalized.
